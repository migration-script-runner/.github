# Migration Script Runner

**Database migrations, under control.**

MSR is an open-source ecosystem of repositories and tools for managing database
migrations. Use its CLI or library APIs with plain SQL, JavaScript, or
TypeScript migration files, and connect databases through adapters.

**MSR Core** provides the shared migration engine, runner API, and CLI. It
handles versioned migrations, validation, execution history, and configurable
backup and rollback workflows. Database adapters provide database-specific
operations, while custom integrations remain possible. MSR does not require a
particular ORM.

## The MSR ecosystem

- **[MSR Core](https://github.com/migration-script-runner/msr-core)** — shared
  migration API, CLI, and workflow.
- **[MSR Firebase](https://github.com/migration-script-runner/msr-firebase)** —
  adapter for Firebase Realtime Database.
- **MSR PostgreSQL** — adapter in development.
