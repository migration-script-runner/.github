# MSR branding assets

Reusable logo and favicon files for the MSR ecosystem. The source branding
archive is maintained in the private `msr-cloud-architecture` repository; these
copies are published here so public repositories and documentation can use
stable links.

## Logos

All marks use the same three-ribbon symbol. Choose the rendering that has enough
contrast for its background:

- `logos/msr-logo-color-flat.png` — flat blue-violet-magenta gradient; a simple
  rendering for small uses.
- `logos/msr-logo-color-glass-translucent.png` — glossy translucent color
  treatment; used in the organization profile and repository README headers.
- `logos/msr-logo-color-glass.png` — glossy glass color treatment.
- `logos/msr-logo-black.png` and `logos/msr-logo-white.png` — solid monochrome
  marks.
- `logos/msr-logo-outline-color.png`, `logos/msr-logo-outline-black.png`, and
  `logos/msr-logo-outline-white.png` — hollow outline treatments.
- `logos/msr-logo-glass-hollow.png` — hollow glossy glass treatment.

## Favicons

- `favicons/msr-favicon.png` — 512 × 512 transparent PNG master.
- `favicons/favicon-32.png` — 32 × 32 PNG.
- `favicons/favicon.ico` — multi-size ICO for browser and documentation sites.

For example, embed the translucent glass logo in a README with:

```html
<img src="https://raw.githubusercontent.com/migration-script-runner/.github/main/assets/branding/logos/msr-logo-color-glass-translucent.png" alt="MSR logo" width="180">
```

Use the same `raw.githubusercontent.com/migration-script-runner/.github/main/`
base URL to reference other files in this directory.
